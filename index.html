Honest hours, not logged hours

StudySync is a daily study tool built around one idea: a timer left running is a lie. Focus Guard watches whether you are actually present, credits allowlisted resources, and marks anything it could not measure as unverified.

What it does

Focus Guard timer

Detects tab-aways, pauses or ends the session, and asks what an interruption meant.

Session receipts

Every session shows clock time vs verified focused time, away time and departures.

Allowed resources

Links the app opened to an allowlisted domain count as study, not distraction.

Physical work mode

Off-screen work is credited conservatively at 75% and never claims to be measured.

Smart task board

Kanban board with homework sync; honest minutes flow back to the card you worked on.

Coworking rooms

QR/code invites, live presence and shared honest minutes with a study partner.

Subject Lab

Interpreter, quizzes with LaTeX, analogies, formula lab, YouTube search (credit-free).

Works offline

Timer, flashcards and homework queue changes locally and sync when you reconnect.

How honest time is calculated

  • Sessions under 2 minutes are discarded as noise.
  • Away spans shorter than the noise window are ignored; longer ones are subtracted.
  • Allowlisted excursions are tracked separately and never subtracted.
  • Only sessions Focus Guard watched end-to-end are marked verified.
  • Physical and retro-logged sessions are always unverified.

Stack

React 19 + TanStack Start (file-based routing, server functions), Tailwind CSS v4 with semantic dark-first tokens, Supabase for database, auth and realtime presence, and a PWA service worker for offline use.
